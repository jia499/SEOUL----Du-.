# SEOUL DU — GitHub Pages сайт

## Файлууд
- `index.html` — сайтын бүтэц, бүх цэс болон мэдээлэл.
- `style.css` — хар хүрэн/алтлаг дизайн, хөдөлгөөнт фон, responsive загвар.
- `script.js` — цэс солих, гар утасны navigation, давхрын tab-ийн үйлдэл.
- `README.md` — суулгах заавар.

## GitHub Pages дээр байрлуулах
1. Энэ хавтас дахь дөрвөн файлыг GitHub repository-ийн үндсэн (`root`) хэсэгт upload хийнэ.
2. Repository → **Settings** → **Pages** руу орно.
3. **Deploy from a branch** сонгоод `main` branch, `/ (root)` сонгон Save дарна.
4. Хэдэн минутын дараа GitHub Pages-ийн үүсгэсэн URL-аар сайтаа нээнэ.

Зургуудыг тусдаа файл болгохгүйгээр CSS дотор base64 хэлбэрээр багтаасан тул дөрвөн файл дангаараа ажиллана. Google Fonts ачаалахад интернэт шаардлагатай; холболтгүй үед системийн fallback фонт хэрэглэнэ.

## Өөрчлөх зүйл
- Нүүрний гол зураг одоогоор таны илгээсэн эхний зураг. Та өөрийн hero зургийг бэлэн болгох үед `style.css` доторх `.hero-image`-ийн background зургийг солино.
- Эмнэлгийн дотоод загварын хэсэгт таны илгээсэн хоёр дахь зураг түр байрласан. Дараа нь интерьерийн зураг тавих бол `.interior-photo`-ийн background-ийг солино.
- Үнэ, өрөөний дугаар, үйлчилгээний текстийг `index.html` дотроос засна.
